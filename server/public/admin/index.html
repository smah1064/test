Employees

Work locations

Employees can only check in inside the radius of their assigned location (or any location if none is assigned). If you add the location's office Wi-Fi, check-ins there are only accepted from that Wi-Fi — the strongest protection against fake GPS.

Blocked punches

Every check-in that was blocked — not on the office Wi-Fi, developer mode on, fake GPS, rooted phone, outside the location, weak GPS or an old selfie.

Office address changes

Each new internet address reported by an office connector. A change about once a day is normal for a dynamic address. An address you don't recognise, or many changes in one day, could mean someone is misusing the connector link: use Replace link.
